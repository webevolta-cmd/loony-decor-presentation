# Loony Decor — website offer presentation (WebEvolta)

Interactive 14-slide presentation. Single self-contained `index.html`
(inline CSS/JS and SVG; fonts load from Google Fonts). Deploys as a static site
with zero configuration on Vercel, Netlify or GitHub Pages.

Slide deep links: append `#s<number>` to the URL, e.g. `/#s14` for the offer slide.
